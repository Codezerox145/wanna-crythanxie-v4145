## Open the dashboard

Visit the [official WANNA-CRY THANXIEE dashboard](https://wanna-crythanxie-v4145-loch.vercel.app). Create your own account or sign in using your registered credentials.

## Pair your WhatsApp account

1. Open the dashboard and sign in.
2. Navigate to the WhatsApp pairing section.
3. Enter your WhatsApp number with the country calling code.
4. Request a pairing code.
5. On your phone, open **WhatsApp → Linked devices → Link a device → Link with phone number instead**.
6. Enter the code shown by the dashboard.
7. Return to the dashboard and confirm that the real session status is connected.

Pairing screens and status labels can change between releases. Follow the instructions displayed by the live dashboard.

**Security:** Never share pairing codes, QR login tokens, or session credentials. Keep private values out of screenshots, GIFs, logs, and Git commits.
