# THANXIEE DEV — Start Card & Brand Assets

This directory contains documentation and naming guidance for WANNA-CRY THANXIEE onboarding and start-card artwork.

## Brand identity

- **Bot/product:** WANNA-CRY THANXIEE
- **Developer:** THANXIEE DEV
- **Visual direction:** premium dark navy/black surfaces, violet and purple highlights, luminous accents, friendly robot mascot.
- **Layout references:** desktop and mobile sign-in design supplied by the project owner.

## Planned artwork

Use descriptive lowercase filenames:

- `start-card.png` — primary onboarding card.
- `start-card-dark.png` — dark theme variant.
- `start-card-mobile.png` — mobile crop.
- `dashboard-preview.png` — supplied desktop/mobile dashboard reference, once committed as an image asset.
- `bot-avatar.png` — approved mascot/avatar artwork.

## Where to use the brand

- Bot profile picture and menu image cards.
- Help, welcome, onboarding, and feature announcement cards.
- Dashboard sign-in, pairing, session-connected, and account screens.
- README previews, release notes, and social announcements.

Use the bot name in headers and place **Powered by THANXIEE DEV** in footers. Keep typography, mascot treatment, and violet accent colors consistent across desktop and mobile.

## Asset and privacy rules

- Do not include live pairing codes, phone numbers, QR login tokens, session credentials, or private account data.
- Use genuine product screenshots for dashboard demonstrations.
- Do not describe a concept mock-up as a live capture.
- The 29-second pairing GIF must show the real authenticated dashboard flow; mask all sensitive values.
